FREQUENTLY ASKED QUESTIONS

Everything You Need to Know

Straightforward answers about PomodoroX features, offline privacy, and device support.

What makes PomodoroX different from web timers? ▾

PomodoroX is built natively in Swift 6 and SwiftUI. It uses under 25MB of RAM, starts instantly, works 100% offline without accounts, and synthesizes continuous procedural acoustics via digital signal processing rather than repetitive audio files.

Is PomodoroX completely free? ▾

Yes. PomodoroX is 100% free and open-source under the MIT License. There are zero subscriptions, paywalls, advertisements, or hidden tiers.

How does PomodoroX protect my privacy? ▾

PomodoroX makes zero network requests. It contains no tracking analytics, telemetry frameworks, or cloud logins. All timer logs, task lists, and focus statistics remain safely on your Mac and iPhone.

How does the procedural ambient audio engine work? ▾

Instead of looping MP3 audio files, PomodoroX generates Real Ocean Waves, Deep Pink Noise, Brown Noise, and Forest Stream on the fly using mathematical biquad filtering and noise algorithms directly through AVAudioEngine.

What macOS keyboard shortcuts are supported? ▾

You can control PomodoroX entirely via keyboard: Space (Play/Pause), ⌘R (Reset), ⌘K (Skip Phase), ⌘= / ⌘- (±5 minutes), ⌘⇧1/2/3 (Focus / Breaks), ⌘N (New Task), and ⌘, (Preferences).

Install PomodoroX on iOS

PomodoroX for iOS can be built and run on your iPhone or iPad using Xcode or distributed via TestFlight / AltStore.

1
Clone the repository:
git clone https://github.com/avantigroupai/pomodoroX.git
2
Generate Xcode Project:
xcodegen generate
3
Build & Deploy to Device:
Select scheme PomodoroX-iOS in Xcode and hit Run (⌘R) on your connected iPhone.

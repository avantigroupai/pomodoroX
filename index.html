Install PomodoroX on iOS

PomodoroX for iOS can be built and run on your iPhone or iPad using Xcode or distributed via TestFlight / AltStore.

1
Clone the repository:
git clone git@github.com:avantigroupai/pomodoroX.git
2
Generate Xcode Project:
xcodegen generate
3
Build & Deploy to Device:
Select scheme PomodoroX-iOS in Xcode and hit Run (⌘R) on your connected iPhone.

Everything You Need to Know

Direct answers to common questions about PomodoroX features, privacy, and compatibility.

PomodoroX is a high-performance, minimalist Pomodoro timer and procedural ambient audio generator engineered natively for macOS 14+ and iOS 17+ using Swift 6, SwiftUI, and AVAudioEngine.

Yes, PomodoroX is 100% free and open-source. There are no subscriptions, ads, in-app purchases, or paywalled features.

PomodoroX operates 100% offline and on-device. It has zero analytics frameworks, zero telemetry, zero cookies, and makes zero network requests. All timer settings, task lists, and statistics are stored locally on your Apple device.

Unlike standard apps that play repetitive 1-minute MP3 audio loops, PomodoroX synthesizes soundscapes in real time via digital signal processing (DSP) biquad filters and mathematical white/pink/brown noise generators. This eliminates ear fatigue and keeps the app footprint tiny (under 25MB).

Yes. PomodoroX features native macOS MenuBarExtra integration. It displays the live remaining countdown directly in your top menu bar with instant play/pause/skip popover controls and a floating Picture-in-Picture mode.

PomodoroX supports full keyboard navigation: Space (Play/Pause), ⌘R (Reset), ⌘K (Skip Phase), ⌘= / ⌘+ (+5 minutes), ⌘- (-5 minutes), ⌘⇧1/2/3 (Focus/Short Break/Long Break), ⌘N (New Task), and ⌘, (Preferences).

On macOS, download the PomodoroX.dmg disk image, open it, and drag PomodoroX.app to your Applications folder. On iOS, build directly from the open GitHub repository via Xcode or deploy with TestFlight.

Install PomodoroX on iOS

PomodoroX for iOS can be built and run on your iPhone or iPad using Xcode or distributed via TestFlight / AltStore.

1
Clone the repository:
git clone git@github.com:avantigroupai/pomodoroX.git
2
Generate Xcode Project:
xcodegen generate
3
Build & Deploy to Device:
Select scheme PomodoroX-iOS in Xcode and hit Run (⌘R) on your connected iPhone.
